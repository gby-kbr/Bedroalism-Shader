## moon_nasa.jpg

Photograph of the near side of the Moon, from the NASA 3D Resources collection
(`Images and Textures/Moon/Moon.jpg` in https://github.com/nasa/NASA-3D-Resources).
NASA states these assets are free and without copyright, see the NASA usage guidelines:
https://www.nasa.gov/nasa-brand-center/images-and-media

Used by `tools/generate_sun_moon.py` as the real surface of `moon_phases.png`.
